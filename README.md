# 資料・動画ライブラリ（GitHub Pages版）

ビルド済みの静的サイトです。`main` に push すると GitHub Actions が自動で GitHub Pages に公開します。

## 仕組み

- 閲覧ページ（`index.html`）は GitHub Pages で表示
- 資料一覧・動画・ファイル本体は既存サーバー（`tagiri-materials.mikutakane.chatgpt.site`）から読み込み
- `/admin` は既存サーバーの管理画面へ転送。資料の追加・編集・削除・並び替えはそこで行う
- 資料を更新してもこのリポジトリの変更は不要。閲覧ページを再読み込みすれば反映される

## 注意

- 管理パスワード・登録済みの資料データはこのリポジトリに含まれない
- 既存サーバーが停止すると、資料一覧・ファイル閲覧・管理機能も使えなくなる
- 動画は MP4（H.264 / AAC）を推奨
