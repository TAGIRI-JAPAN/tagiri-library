# TAGIRI 資料・動画 — GitHub Pages版

このZIPはビルド済みです。Node.jsのインストールやビルドは不要です。

## GitHubへの配置

1. ZIPを解凍します。ZIP自体はアップロードしません。
2. GitHubで新しい公開リポジトリを作成します。推奨名は tagiri-library です。
3. Add file → Upload files で、解凍した中の全ファイル・フォルダをアップロードし、Commit changes を押します。
4. リポジトリの一番上に index.html と assets、images、admin が並んでいることを確認します。外側のフォルダごと置かないでください。
5. Settings → Pages → Source を Deploy from a branch にします。
6. Branch を main、フォルダを / (root) にして Save を押します。
7. Pagesの画面に表示される公開URLを開きます。反映には数分かかる場合があります。

リポジトリ名が変わっても画像と画面のファイル参照が動くよう、相対パスで組んであります。

## 資料・動画の登録

閲覧画面はGitHub Pagesで表示し、公開資料の一覧と動画・ファイルは公開済みサーバーから読み込みます。
「管理画面」を押すと https://tagiri-materials.mikutakane.chatgpt.site/admin に移動します。
パスワードを入力して、追加・編集・削除・並び替え・アップロードを行ってください。
登録や変更の後、GitHub Pages側を再読み込みすると反映されます。資料更新のたびにGitHubへの再アップロードは不要です。

動画や大容量ファイルをGitHubへ直接置く必要はありません。
1ファイル20GBまでの分割送信、一時停止と再開に対応します。
20GBの実ファイル全体の送信試験は未実施です。動画はMP4（H.264 / AAC）を推奨します。

## 構成

GitHub Pagesだけでは管理パスワードの認証やファイル保存はできないため、管理画面と保存先は既存サーバーを利用します。
このZIPだけで保存サーバーを移転・複製することはできません。既存サーバーが停止すると、資料一覧・ファイル閲覧・管理機能も利用できなくなります。
ZIPに管理パスワードや登録済みの動画・資料は含みません。
